4. WHERE YOUR DATA IS STORED

Kivo is designed as a local-first application.

Your vault data is stored on your device.

Structured information may be stored in Kivo's local database, while files may be stored inside Kivo's application data folder.

When you add a file to Kivo, Kivo may create its own copy inside the Kivo data folder.

Because of this:

- Moving the original file does not necessarily remove the copy stored by Kivo.
- Deleting the original file does not necessarily remove the copy stored by Kivo.
- Removing a file from Kivo does not necessarily affect the original file outside Kivo unless clearly stated.

5. WHEN KIVO USES THE INTERNET

Kivo is designed to operate primarily offline.

Some actions may require an internet connection.

SAVED LINK ICONS

When you save a website link, Kivo may contact that website or a related service to retrieve a small website icon.

The website may receive normal technical information associated with that request, similar to a request made by a web browser.

Kivo may store downloaded icons locally using internal or non-readable filenames.

This helps prevent the icon storage folder from becoming a readable list of websites stored in your vault.

OPENING EXTERNAL LINKS

When you choose to open a saved website, your default web browser may connect to that website.

That connection is handled by your browser and the website itself.

VAULT CONTENTS

Kivo does not intentionally upload your notes, files, passwords, or other vault contents to a Kivo server.

If future versions introduce optional online services, those features and their data behavior should be disclosed before use.

6. BACKUPS ARE YOUR RESPONSIBILITY

Kivo does not guarantee that your local data can always be recovered.

Unless you enable a specific backup feature, Kivo does not automatically create external backups of your vault.

Your vault may be lost if your device is:

- Lost
- Stolen
- Damaged
- Reset
- Reformatted
- Affected by hardware failure
- Affected by file corruption

You should regularly create backups.

You can use:

Settings > Backup and Restore

to create a backup in a folder you choose.

For better protection, keep at least one backup on another device or storage location, such as:

- USB drive
- External drive
- Another computer
- Another secure storage location

Backups can later be restored using Kivo's restore feature.

However, unless a specific part of your vault is encrypted, App Lock alone does not guarantee that files stored on your computer cannot be accessed directly through the operating system.

Anyone with sufficient access to your computer or storage device may still be able to access unencrypted files.

MASTER PASSWORD RECOVERY

Kivo does not guarantee recovery of your Master Password.

8. PASSWORD MANAGER

Kivo may include a local Password Manager for storing login credentials.

Password Manager entries may contain:

- Service or website name
- Username
- Email address
- Password
- Website URL
- Notes
- Categories
- Tags

Saved passwords must not be stored as readable plain text.

Kivo should encrypt saved password information before storing it locally.

Passwords may only be decrypted when the Password Manager is unlocked.

PASSWORD MANAGER PASSWORD

The Password Manager may use its own password or security key.

This password may be separate from the main Kivo App Lock password.

If this password cannot be recovered, encrypted password entries may become permanently inaccessible.

Kivo cannot guarantee recovery of encrypted passwords if the required password or encryption key is lost.

9. PASSWORD GENERATOR

Kivo may include a Password Generator.

Generated passwords are created locally and are not automatically saved.

A generated password is only stored if you choose to use and save it as part of a Password Manager entry.

Kivo should use a cryptographically secure random generator for password generation.

The generator may support:

- Password length
- Uppercase letters
- Lowercase letters
- Numbers
- Symbols
- Passphrases
- Character exclusions
- Password strength estimates

Password strength indicators are estimates and do not guarantee that a password cannot be compromised.

10. DELETING ITEMS

Items deleted from Kivo may first be moved to Trash.

When an item is permanently deleted from Trash, Kivo will attempt to remove the associated stored data.

Permanent deletion cannot normally be undone.

Before permanently deleting important information, make sure you have any backup you may need.
